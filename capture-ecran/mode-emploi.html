1. Installer (une seule fois)

Option A — l'installateur (conseillé)

  1. Téléchargez Capture-ecran-PLAI-installateur.exe depuis la page de téléchargement, puis double-cliquez dessus. Aucun droit d'administrateur n'est nécessaire.
  2. Si Windows affiche « Windows a protégé votre ordinateur » (le programme n'est pas signé) : Informations complémentaires › Exécuter quand même.
  3. Dans l'assistant, choisissez si vous voulez un raccourci sur le bureau et le lancement automatique avec Windows, puis terminez. Le programme se retrouve aussi dans le menu Démarrer.

Option B — sans installation (zip)

  1. Téléchargez le .zip. Avant d'extraire : clic droit sur le zip › Propriétés › cochez « Débloquer » › OK (la case n'apparaît que si Windows a marqué le fichier comme venant d'Internet).
  2. Clic droit › Extraire tout…, puis double-clic sur Capture-ecran-PLAI.exe dans le dossier extrait.
Est-il sûr ? Chaque version est analysée par Microsoft Defender et par ClamAV pendant sa fabrication ; le rapport et l'empreinte du fichier (SHA-256) sont publiés avec la version sur la page des versions. Un résultat propre ne fait pas disparaître l'avertissement ci-dessus, qui dépend de la signature numérique et de la notoriété du programme, pas de la présence d'un virus. Si votre école bloque les programmes inconnus, remettez le rapport à votre service informatique.

Rien n'est envoyé sur Internet.

Où sont mes captures ? Au premier lancement, le programme crée sur votre bureau un dossier « Capture-ecran-jfb4plai » (avec le logo jfb4plai) et l'ouvre. Chaque série de captures y a son sous-dossier (date et heure). Le chemin est toujours affiché en haut de la fenêtre : cliquez dessus pour ouvrir le dossier. Dans chaque série : les images annotées, un dossier originales (sans annotation), audio, et vos exports (document.docx, fiche_pas_a_pas.html, video).

⚠ Bureau synchronisé (OneDrive…) : sur beaucoup d'ordinateurs, le bureau est copié automatiquement dans le cloud de Microsoft. Si vos captures peuvent montrer des noms ou des écrans d'élèves, choisissez un autre dossier (Réglages…) ou le choix « Documents » proposé au premier lancement. Le programme vous avertit quand il détecte ce cas (détection indicative : en cas de doute, vérifiez vous-même).

Ouvrir facilement le programme

Contrairement à l'outil de capture de Windows (Windows+Maj+S), mes raccourcis ne fonctionnent que si le programme est ouvert. La combinaison Windows+Maj+S est réservée par Windows : j'utilise Ctrl+Maj+F9 à F12. Pour l'avoir toujours sous la main :

  • Raccourci sur le bureau : proposé au premier lancement ; créé ou retiré dans Réglages › Ouvrir facilement (avec un raccourci dans le menu Démarrer).
  • Lancement automatique à l'ouverture de Windows : même endroit. Le programme démarre alors réduit dans la barre des tâches.
  • Épingler à la barre des tâches : clic droit sur le raccourci › Épingler à la barre des tâches.
  • Si le programme est déjà ouvert, un second lancement ramène simplement la fenêtre au premier plan.
  • Windows+Maj+Q rouvre la fenêtre quand le programme tourne (par exemple lancé au démarrage de Windows). Si cette combinaison est déjà prise par un autre programme, le message d'état l'indique : changez-la dans Réglages › Raccourcis clavier.
  • Et si le programme est fermé ? Windows n'autorise pas la touche Windows pour lancer un programme. Alternative : Réglages › Ouvrir facilement, case « Les raccourcis s'ouvrent aussi avec Ctrl+Alt+Q ». Sur un clavier belge, Ctrl+Alt est la touche AltGr : à désactiver si vous tapez souvent AltGr+Q. (Combinaison non vérifiée sur un vrai poste.)
Avant de créer un raccourci, déplacez le dossier extrait du zip (Capture-ecran-PLAI) à un endroit durable, par exemple dans Documents : le raccourci pointe vers ce dossier, et il ne fonctionnera plus si vous le videz (Téléchargements) ou le supprimez. Le programme vous prévient quand il tourne depuis « Téléchargements » ou un dossier temporaire. Pour réparer un raccourci après un déplacement : relancez le programme depuis son nouvel emplacement et revalidez Réglages › Ouvrir facilement.

Mettre à jour le programme

Avec l'installateur : téléchargez le nouvel installateur et lancez-le. Il ferme le programme s'il est ouvert, remplace l'ancienne version et garde vos raccourcis. Vos captures (dossier « Capture-ecran-jfb4plai » du bureau) et vos réglages sont rangés en dehors du programme : ils sont conservés. Le numéro de version s'affiche dans la barre de titre.

Si vous aviez la version « zip » : l'installateur ne supprime pas l'ancien dossier ; après l'installation, vous pouvez le supprimer, ainsi que ses anciens raccourcis.

Avec le zip : fermez le programme (clic droit sur son icône dans la barre des tâches › Fermer), téléchargez et Débloquez le nouveau zip, puis extrayez-le dans le même dossier que l'ancienne version en acceptant de remplacer les fichiers : vos raccourcis continuent de fonctionner. Extrait ailleurs, les raccourcis visent encore l'ancien dossier : supprimez-le, lancez la nouvelle version, puis recochez les raccourcis dans Réglages.

Désinstaller (version installée) : Paramètres de Windows › Applications › Capture d'écran PLAI › Désinstaller. Vos captures et réglages ne sont pas supprimés.

2. Photographier un menu déroulant

  1. Lancez le programme (une petite fenêtre s'ouvre ; vous pouvez la réduire).
  2. Ouvrez votre menu comme d'habitude (clic sur Fichier, clic droit…).
  3. Sans cliquer ailleurs, appuyez sur le raccourci :
RaccourciEffet
Ctrl+Maj+F9tout l'écran
Ctrl+Maj+F10vous choisissez une zone (le menu est déjà « figé »)
Ctrl+Maj+F11la fenêtre active seulement
Ctrl+Maj+F12démarre / arrête la série de clics
Ctrl+Maj+F8capture simple, comme Windows+Maj+S : vous tracez une zone, elle part dans le presse-papiers (Ctrl+V pour coller). Sans pointeur ni halo jaune. Par défaut : presse-papiers seulement (aucun fichier). Réglages › Capture simple permet aussi de la ranger dans votre série, ou de l'ouvrir dans l'éditeur
Ctrl+Maj+F7filme l'écran (démarre, puis arrête) : voir 4. Filmer l'écran en vidéo
Windows+Maj+Qrouvre la fenêtre du programme (réduite dans la barre des tâches)

Un bip confirme la capture. Sur un portable, ajoutez la touche Fn si besoin. Les raccourcis se changent via Réglages… (évitez Ctrl+Alt : c'est la touche AltGr du clavier belge).

Si le raccourci ne marche pas : bouton « Dans 3 secondes », puis ouvrez votre menu pendant le décompte. Le pointeur est dessiné avec un halo jaune pour montrer où vous avez cliqué (désactivable).

3. La série de clics (une capture numérotée par clic)

Idéal pour expliquer une manipulation : faites-la une fois, le programme prend une image à chaque clic.

  1. Cliquez sur ● Enregistrer mes clics (ou Ctrl+Maj+F12). La fenêtre se réduit. Pour la rouvrir et voir la liste se remplir en direct : Win+Maj+Q. Le bouton devient ■ Arrêter l'enregistrement (N clics).
  2. Faites votre manipulation normalement. Un bip = une étape enregistrée. Chaque image reçoit un cercle rouge autour du clic, une pastille numérotée et la légende « Cliquez ici ».
  3. Arrêtez avec Ctrl+Maj+F12. Évitez de cliquer sur la barre des tâches pour rouvrir la fenêtre : ce clic serait enregistré.
  4. Améliorez chaque étape (double-clic sur la ligne) : légende, flèche, voix.

Moment de l'image : juste avant le clic (recommandé : on voit le menu ouvert et le pointeur sur l'élément à cliquer) ou 0,5 s après (on voit le résultat). Un double-clic est fusionné en une seule étape. Seuls les clics gauche et droit sont enregistrés (ni glisser-déposer, ni clavier). Après avoir supprimé ou déplacé des étapes : bouton ↻ Renuméroter.

Sélectionner plusieurs captures : case « Tout sélectionner » sous la liste, ou Ctrl+clic (une par une) / Maj+clic (une plage). La sélection multiple sert à supprimer, déplacer (▲ ▼) et exporter : le programme demande alors s'il faut exporter seulement la sélection ; les fichiers portent le suffixe _selection, rien n'est écrasé.

4. Filmer l'écran en vidéo

Pour montrer une manipulation en mouvement, avec votre voix. Le résultat est un fichier MP4 (image 15 par seconde, son AAC) rangé dans le dossier de la série en cours. C'est distinct de la « vidéo sous-titrée » faite à partir de captures (voir plus bas).

  1. Dans la fenêtre du programme, choisissez Filmer : une zone (choix par défaut), tout l'écran ou la fenêtre active. Cochez ou non Enregistrer aussi le micro (coché par défaut). Facultatif : indiquez un nombre de minutes dans Arrêt automatique après (par exemple 10) pour que l'enregistrement s'arrête tout seul ; laissez vide pour arrêter vous-même.
  2. Cliquez sur 🎬 Enregistrer une vidéo, ou appuyez sur Ctrl+Maj+F7 (ce raccourci se change dans Réglages…). La fenêtre du programme se retire pour ne pas être filmée.
  3. Une zone : l'écran se fige, tracez la zone à filmer avec la souris (Échap annule). La zone doit faire au moins 16 × 16 pixels.
  4. Patientez 3 à 4 secondes : le message « Préparation de l'enregistrement… » s'affiche pendant l'ouverture du micro. Un bip signale que l'enregistrement a commencé : parlez et agissez à partir de ce bip.
  5. Une barre sombre reste affichée au premier plan avec le temps écoulé, le bouton ■ Arrêter et le rappel « ou Ctrl+Maj+F7 ». Avec un arrêt automatique, elle affiche le temps restant (« reste 03:12 »), qui passe à l'orange sur les 10 dernières secondes, et un bip prévient 10 secondes avant la fin. Elle se place hors de la zone filmée (au-dessus, sinon en dessous, à droite ou à gauche) et se déplace en la faisant glisser à la souris.
  6. Pour arrêter : cliquez sur ■ Arrêter ou appuyez de nouveau sur Ctrl+Maj+F7. Comptez 1 à 2 secondes de finalisation, puis le dossier de la série s'ouvre avec le fichier video_AAAA-MM-JJ_HHhMMmSS.mp4.

Pendant l'enregistrement, Windows+Maj+Q ne rouvre pas la fenêtre du programme (elle se poserait sur la zone filmée) : il ramène seulement la barre au premier plan. La fenêtre revient à l'arrêt. Les captures par raccourci et la série de clics sont refusées jusqu'à l'arrêt de la vidéo.

Pointeur : il apparaît dans la vidéo si Réglages… › Montrer le pointeur de la souris est coché. Écran entier : la barre ne peut pas se placer hors de l'image ; Windows est alors prié de ne pas l'inclure dans l'enregistrement (essai de contrôle du 21/10/2026 sur une image fixe, Windows 11 ; sur Windows 10 antérieur à la version 2004, cette exclusion n'est pas garantie).

Ce que cette fonction ne fait pas :

  • l'arrêt automatique se règle en minutes entières, de 1 à 600 (pas d'heure de fin) et compte à partir du début de l'image, pas de la préparation du micro ;
  • les fichiers sont lourds : environ 29 Mo pour 1 minute d'écran entier (mesuré sur un seul écran, à titre d'exemple ; une petite zone pèse moins) ;
  • pas de pause ni de montage : un enregistrement = un fichier ;
  • le son de l'ordinateur (vidéo, musique, visioconférence) n'est pas enregistré : seulement le micro ;
  • si aucun micro n'est détecté ou s'il ne démarre pas, la vidéo est faite sans son et la barre d'état le dit (« Micro indisponible : image seule ») ; sinon le premier micro détecté par Windows est utilisé, sans choix dans le programme ;
  • la vidéo n'apparaît pas dans la liste des captures de la série et n'entre pas dans le document Word ni la fiche HTML ;
  • dimensions arrondies au nombre pair (jusqu'à 1 pixel de moins) ; les fenêtres protégées par certains lecteurs vidéo peuvent apparaître noires (non vérifié).

Le programme fournit son propre ffmpeg (encodage H.264 de Windows, voir plus bas). La synchronisation du son et de l'image a été mesurée sur les durées, pas contrôlée à l'oreille : si vous constatez un décalage, signalez-le.

5. Annoter, légender, enregistrer sa voix

L'éditeur s'ouvre tout seul après chaque capture. Choisissez un outil, une couleur, une taille, puis glissez sur l'image.

OutilUsage
➚ Flèchemontrer un bouton (Maj = flèche bien droite)
▭ Cadre · ◯ Ovale · ▮ Surlignerentourer, mettre en évidence
T Textecliquer puis écrire ; double-clic sur un texte pour le corriger
① Numéroposer 1, 2, 3… pour les étapes
✎ Crayondessin libre
■ Masqueraplat noir définitif sur un prénom, un nom d'élève, une adresse (RGPD)
▦ Pixellisereffet de mosaïque, déconseillé pour les données personnelles : un flou léger peut parfois être partiellement reconstitué
✂ Recadrergarder seulement une zone
☝ Déplacerdéplacer un objet (Suppr pour l'effacer) ; une couleur ou une taille choisie s'applique à l'objet sélectionné

Ctrl+Z annule, Ctrl+Y rétablit. Copier l'image puis Ctrl+V dans Word, Teams ou un courriel. Ouvrir dans Paint fixe les annotations dans l'image puis ouvre Paint (vous ne pourrez plus les déplacer dans notre éditeur).

Masquer remplace la zone par un aplat noir, et ce masque est fixé dans l'image d'origine dès l'enregistrement (le dossier originales ne contient plus la donnée cachée). Sans retour possible : c'est voulu. Si une flèche ou un texte avait été posé avant le masque, supprimez-le plutôt que de le déplacer. Quand « Copier dans le presse-papiers » est coché, c'est l'image finale (masques compris) qui est copiée à l'enregistrement. Pour partager, utilisez les exports (Word, HTML, vidéo), pas le dossier de la série. Les séries d'avant la v1.1.2 : bouton « 🔒 Masques définitifs ».

La légende (en bas de l'éditeur) devient le sous-titre de la vidéo : une phrase courte par étape, à l'impératif (« Cliquez sur Fichier »).

Ma voix : 🎙 Enregistrer ma voix, lisez la légende, ⏹ Arrêter, ▶ Écouter pour vérifier, ✖ Effacer pour recommencer. Il faut un micro autorisé dans Paramètres Windows › Confidentialité › Microphone. Parlez dans une pièce calme, à 20 cm du micro.

6. Fabriquer une fiche, un document Word ou une vidéo

Dans la fenêtre principale, réorganisez les captures avec ▲ ▼, puis :

  • 📝 Document Word : document.docx (A4), un titre « Étape n », la légende et l'image. Police Verdana 12, vrais titres Word (navigation, lecteurs d'écran) et texte alternatif sur chaque image.
  • 📄 Fiche HTML/PDF : page web numérotée, imprimable ou « Enregistrer au format PDF ».
  • 🎬 Vidéo : crée le dossier video dans la série.

Option : dans Réglages…, cochez l'ajout du logo jfb4plai en haut des fiches et documents.

7. Créer la vidéo sous-titrée (à partir de captures)

Dernière vérification des informations sur Clipchamp : 16/10/2026, par recherche web (sources secondaires). À contrôler dans l'application, les menus évoluent.

Voie 1 — directe, un seul clic

Le dossier video contient : image_001.png… (1920×1080, sous-titre incrusté), soustitres.srt, durees.txt, voixoff.wav si vous avez enregistré votre voix, et video.mp4 si le programme ffmpeg est présent. La durée de chaque image suit la longueur de la légende (3 à 15 s) ; avec une voix, l'image reste au moins aussi longtemps que la parole (+ 0,6 s) : elle n'est jamais coupée.

Voie 2 — sans ffmpeg : assembler dans Clipchamp (Windows 11)

  1. Ouvrez Clipchamp › Créer une vidéo.
  2. Glissez les image_001.png… sur la ligne de temps, dans l'ordre, et réglez leur durée (voir durees.txt).
  3. Glissez voixoff.wav sous les images : elle est déjà synchronisée si vous gardez les durées par défaut.
  4. Exporter › 1080p : fichier MP4 (l'export 1080p sans filigrane de la version gratuite est indiqué par des sources secondaires ; à vérifier).

Les sous-titres sont déjà dans les images : inutile d'importer le .srt (je n'ai pas pu confirmer que Clipchamp accepte cet import).

Voie 3 — le MP4 automatique (ffmpeg fourni)

L'installateur (et le dossier zippé) contient son propre ffmpeg.exe, dans le dossier ffmpeg du programme : le MP4 se crée donc sans rien installer. Le programme l'utilise en premier ; Réglages… › ffmpeg.exe › Parcourir… permet d'en imposer un autre, qui passe alors avant.

Licence : ce ffmpeg est une version sous licence LGPL v3 (sans composant GPL). Le texte de la licence et l'adresse du code source sont dans le dossier ffmpeg : LICENSE-ffmpeg.txt et SOURCES-ffmpeg.txt. Le programme le lance comme programme séparé : vous pouvez le remplacer par un autre ffmpeg.exe.

Version Python (Lancer.bat) ou ancienne installation sans ffmpeg : le programme cherche ffmpeg tout seul (PATH de Windows, installations winget, Chocolatey, Scoop, C:\ffmpeg). Sinon : winget install Gyan.FFmpeg, puis fermez et rouvrez le programme.

Conseils pour de bonnes vidéos

  • Une idée par écran, 6 à 12 mots de légende, verbes d'action.
  • 8 à 10 écrans au plus ; plusieurs courtes vidéos plutôt qu'une longue.
  • Masquez (■) toute donnée d'élève avant de partager.
  • Pour des élèves à besoins spécifiques : texte blanc sur bande noire (contraste élevé), phrases courtes, et proposez aussi la fiche imprimée. Votre voix double l'information écrite.
