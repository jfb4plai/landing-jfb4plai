VolubilActif

Remplacer la frappe au clavier par la dictée vocale, dans n'importe quelle application ouverte : navigateur, traitement de texte, messagerie. Un raccourci, on parle, le texte s'insère là où se trouve le curseur. Pour les élèves pour qui écrire est un obstacle (dysgraphie, dyslexie, fatigue motrice), et pour toute personne qui préfère dicter.

⬇ Télécharger l'installateur (Windows) ⬇ Version Mac (page des versions)

Gratuit, sans compte, sans abonnement. Tout se passe sur votre ordinateur : la voix n'est jamais envoyée sur Internet. La seule exception : le tout premier téléchargement du modèle de transcription (environ 574 Mo pour le modèle Turbo). Toutes les versions, avec l'empreinte SHA-256 de chacune : page des versions.

Installer

  1. Téléchargez VolubilActif-Windows-installateur.exe et double-cliquez dessus. Aucun droit d'administrateur n'est nécessaire pour une installation « pour moi seul ».
  2. Si le navigateur bloque le fichier (« pas fréquemment téléchargé ») : ouvrez les téléchargements (Ctrl+J), cliquez sur les trois points puis Conserver.
  3. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires › Exécuter quand même.
  4. Suivez l'assistant. Une case propose de lancer VolubilActif à l'ouverture de Windows (conseillé : la dictée par raccourci ne marche que si le programme tourne). Lancez ensuite le programme.

Mettre à jour : VolubilActif vérifie lui-même s'il existe une nouvelle version, la télécharge en arrière-plan et vous propose de redémarrer pour l'appliquer (jamais sans votre accord). Désinstaller : Paramètres de Windows › Applications.

Mac : ouvrez le fichier .dmg, glissez VolubilActif dans Applications. Au premier lancement, clic droit sur l'application puis Ouvrir (programme non signé). Les autorisations Microphone et Accessibilité sont demandées à l'usage. Détails dans le mode d'emploi du dépôt.

Pourquoi cet avertissement ? Le programme n'est pas signé numériquement. Il est donc inconnu de Windows et de macOS. Cela ne veut pas dire qu'il est dangereux.

Est-il sûr ? Ce qui est vérifié, et ce qui ne l'est pas

  • Code source ouvert : github.com/jfb4plai/VolubilActif. Les installateurs sont construits automatiquement à partir de ce code.
  • Analyse antivirus : à partir de la prochaine version, chaque version est analysée par Microsoft Defender et par ClamAV pendant sa fabrication, et n'est publiée que si aucune menace n'est signalée. Le rapport est publié avec la version, sur la page des versions, avec l'empreinte SHA-256 du fichier (à recalculer avec Get-FileHash dans PowerShell).
  • Ce que cela ne change pas : un résultat propre ne fait pas disparaître l'avertissement de Windows, qui dépend de la signature et de la notoriété du fichier. Si votre école bloque les programmes inconnus, remettez le rapport d'analyse à votre service informatique.
  • Mode « maintenir les touches » (optionnel) : il utilise une écoute clavier du système, capable de voir toutes les frappes (le programme ne réagit qu'au raccourci choisi et n'enregistre rien d'autre). Certains antivirus la signalent au premier lancement. Le mode par défaut (un appui pour démarrer, un autre pour arrêter) ne l'utilise pas.

Ce que fait le programme

  • Dictée par raccourci, dans n'importe quelle application. Avec « Maintenir les touches enfoncées », l'enregistrement dure tant que les touches restent enfoncées. Choisissez un raccourci sans lettre (par exemple Ctrl+Maj+Espace) : une lettre peut réagir sur une autre touche selon le clavier.
  • Ponctuation dictée sans IA : dire « virgule », « point d'interrogation », « à la ligne » insère le signe.
  • Mode examen : la voix est transcrite telle quelle, sans passage par un modèle d'IA qui pourrait reformuler.
  • Mode privé : sur un ordinateur partagé, aucune dictée n'est conservée sur la machine.
  • Dictionnaire partageable : l'enseignant prépare le vocabulaire de son cours et le distribue à ses élèves.
  • Mode amélioré (facultatif) : ponctuation automatique et gestion des « en fait non… » grâce à Ollama, un petit modèle de langage installé sur l'ordinateur (8 Go de RAM ou plus conseillés). Sans Ollama, le programme revient au nettoyage simple.

Limites annoncées

  • C'est un outil de compensation, pas de remédiation : il ne corrige pas l'orthographe de l'élève, il l'évite. À utiliser après diagnostic, en accord avec l'équipe.
  • Il ne convient pas pendant l'apprentissage du geste d'écriture (début du primaire).
  • Les modèles de reconnaissance vocale sont entraînés surtout sur des voix d'adultes : la précision baisse avec les voix jeunes et le bruit de classe. À tester avec l'élève avant d'en faire un outil du quotidien.
  • Dicter à voix haute expose son texte : prévoir un endroit calme ou un micro-casque.
  • Sur un parc informatique géré, l'installation peut demander l'accord du technicien.
